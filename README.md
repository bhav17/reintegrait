# ReintegrAIt

An AI copilot for Chicago reentry case managers: voice-to-case-note drafting and referral ranking by likelihood of acceptance. The case manager makes every decision about the client.

See [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md) for goals and the MVP plan.

## Prototype

The Step 1 client note prototype is in [app/step1-client-note](app/step1-client-note). See its README to run it and its acceptance test.
